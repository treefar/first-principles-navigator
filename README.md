# 第一性原理｜核心問題導航器

把模糊問題拆成事實、假設與最小驗證，留下可以持續追蹤的決策紀錄。

[開啟公開版](https://treefar.github.io/first-principles-navigator/)

![第一性原理核心問題導航器預覽](preview.webp)

## 主要功能

- 快速、標準、深度三種分析模式
- 事實與假設分離、連續追問與核心問題重述
- 假設風險矩陣與優先驗證清單
- 案例庫、決策日誌、結果回填與個人範本
- Markdown、主管摘要、教學講義、Obsidian 與工單格式匯出
- 純前端單檔執行，資料保存在瀏覽器本機

## 隱私說明

本工具不會把分析內容傳到伺服器。清除瀏覽器網站資料或改用其他裝置前，請先使用「匯出完整備份」。
